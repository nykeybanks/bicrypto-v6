# QUANTUMYIELD UI

This repository now includes a standalone dashboard UI for a yield-focused crypto platform called QUANTUMYIELD.

Files:
- `index.html` — main dashboard structure
- `styles.css` — dark luxury dashboard styling
- `app.js` — nav and form interaction logic

Quick start:
1. Open `index.html` in a browser, or
2. Serve the folder with a local web server:

   python3 -m http.server 8000

Then visit:
- http://localhost:8000

This is intentionally built as a standalone front-end mockup without external dependencies.
